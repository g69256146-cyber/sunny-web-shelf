# MATHRU — ICU Palliative Care Research

Website for the MATHRU ICU Palliative Care Research Project, Kasturba Medical
College, Manipal (MAHE).

## Tech stack

- Vite
- TypeScript
- React
- Tailwind CSS
- shadcn/ui

## Local development

```sh
npm install
npm run dev
```

## Project structure

- `src/pages` — routed pages (Home, About, Team, Outputs, Contact)
- `src/components` — shared UI and layout components
- `public/documents` — downloadable study documents
